# Sage Ideas — Site Video Library (build plan)

All 16:9, on-site only, built on the same motion template + original score + the
cyan→rose→green "proof-particle" system as the hero intro (`intro2.html`). Reuse
= fast + consistent. Prioritized in phases at the bottom.

Brand system (locked): Instrument Serif + JetBrains Mono, #09090B base, green #10b981 /
cyan #22d3ee / rose #f43f5e / purple #a78bfa. Thesis = PROOF (real numbers, real tools,
"every claim links to an artifact"). Voice = Jason (ElevenLabs), score = original.

## Recommended build order (impact-first)
- **Phase 1 — must-have (converts):** ✅ Intro · The one-week audit · Service trio (LLM/RAG eval, Test automation & CI, Workflow automation) · 1 case study (red→green)
- **Phase 2 — hook & educate:** "Why AI demos lie" · "LLM-as-judge" · "Evals vs tests vs gates" · "How the proof gate works"
- **Phase 3 — close & complete:** How-we-work · What-you-get · objection-handlers · Nexural/Academy tours
- **Phase 4 — polish:** ambient loops, 30s ultra-short, "every claim links to an artifact"

## The system note
Don't build these as one-offs. The template (`intro2.html`) + score generator + proof-particle
motif is a **reusable engine** — like the Nexural thumbnail library. Each new video = new copy +
new scene content in the same system. That's how a real library gets built without it looking
like 20 different videos.
