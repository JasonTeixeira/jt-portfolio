La disciplina · por qué a un comprador debería importarle

Grado producción, no prueba de concepto.

Arquitectura de seguridad
  • Row-level security on every one of 244 public tables
  • Append-only admin audit log enforced by database triggers
  • Zod-validated writes on the highest-risk admin paths
  • Locked function search_path, env-gated admin 2FA
La honestidad como función
  • A public track-record page that renders real engine output
  • Build gates that block fake or stale data from shipping
  • Revalidated every 5 minutes — not a screenshot from a good day
Operado, no solo lanzado
  • 86 scheduled jobs keep the data and content fresh nightly
  • Sentry error tracking + Vercel analytics wired in
  • One person owns build, deploy, data, billing and support

Sistema acompañante · el motor de IA en Discord

Un motor de IA que opera una comunidad en piloto automático.

Qué es

A separate Node service — discord.js + GPT-4o + Supabase + Alpaca — deployed on Railway, posting market-cycle content and answering members across the server around the clock.

La escala
  • 41 channels orchestrated
  • 83 scheduled jobs on a market-hours cadence
  • 76 database migrations, 299 test files
Por qué importa

Es prueba de que puedo llevar un sistema de IA más allá de la demo — a algo que corre sin supervisión, en horario, conectado a datos reales de bróker y de mercado, y no se cae.
